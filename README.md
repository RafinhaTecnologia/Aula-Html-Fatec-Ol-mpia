\# 📚 Repositório de Atividades - HTML e Desenvolvimento Web



Repositório acadêmico dedicado ao armazenamento, versionamento e entrega das atividades práticas, exercícios e Situações de Aprendizagem desenvolvidas para a disciplina de \*\*HTML e Desenvolvimento Web\*\* da \*\*FATEC Olímpia\*\*.



Este ambiente foi estruturado para o acompanhamento contínuo do progresso na disciplina e serve como canal oficial para a avaliação e correção dos trabalhos pelo docente.



\---



\## 📂 Estrutura do Repositório



O conteúdo está organizado modularmente de acordo com a evolução das aulas e laboratórios:



\* `ATIVIDADES AULAS/` — Páginas HTML desenvolvidas em aula, exercícios práticos e recursos de desenvolvimento:

&#x20; \* `IMAGENS/` — Repositório de mídias e ativos visuais utilizados nas páginas web.

&#x20; \* `static/css/` — Arquivos de estilização e folhas de estilo modulares (`estilo.css`).

\* `AULAS DOC/` — Roteiros, documentações de apoio e Situações de Aprendizagem disponibilizados pelo professor.



\---



\## 🛠️ Tecnologias Utilizadas



\* \*\*HTML5\*\*: Estruturação semântica e construção de páginas web.

\* \*\*CSS3\*\*: Estilização, layout e conceitos de modularização.

\* \*\*Git \& GitHub\*\*: Controle de versão e versionamento de código-fonte.
