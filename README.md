# 📚 Repositório de Atividades - HTML e Desenvolvimento Web

Repositório acadêmico dedicado ao armazenamento, versionamento e entrega das atividades práticas, exercícios e Situações de Aprendizagem desenvolvidas para a disciplina de **HTML e Desenvolvimento Web** da **FATEC Olímpia**.

Este ambiente é utilizado para o acompanhamento contínuo da disciplina e serve como canal oficial para a entrega e correção das atividades pelo docente.

---

## 📌 1. Estrutura do Repositório

O conteúdo está organizado modularmente conforme a evolução das aulas e laboratórios:

* `ATIVIDADES AULAS/` — Diretório principal contendo as páginas HTML desenvolvidas em aula, exercícios e recursos práticos:
  * `IMAGENS/` — Repositório centralizado de mídias e ativos visuais utilizados nas páginas.
  * `static/css/` — Folha de estilo centralizada (`estilo.css`) para modularização e estilização dos documentos.
* `AULAS DOC/` — Roteiros, documentações de apoio e Situações de Aprendizagem disponibilizados pelo professor.

---

## 🛠️ 2. Tecnologias e Conceitos Aplicados

| Tecnologia / Conceito | Descrição |
| :--- | :--- |
| **HTML5 Semântico** | Estruturação de páginas com uso de tags limpas e organizadas. |
| **CSS3 & Estilização** | Estilização externa, reset de propriedades e alinhamento visual de elementos. |
| **Modularização** | Separação correta entre código-fonte, folhas de estilo e ativos visuais. |
| **Git & GitHub** | Controle de versão por meio de commits estruturados e envio contínuo para avaliação. |
