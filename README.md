# 📚 Repositório de Atividades - HTML e Desenvolvimento Web

Repositório acadêmico dedicado ao armazenamento, versionamento e entrega das atividades práticas, exercícios e Situações de Aprendizagem desenvolvidas para a disciplina de **HTML e Desenvolvimento Web** da **FATEC Olímpia**.

Este ambiente é utilizado para o acompanhamento contínuo da disciplina e serve como canal oficial para a entrega e correção das atividades pelo docente.

---

## 📌 1. Estrutura do Repositório

O conteúdo está organizado conforme a evolução das aulas e entregas da disciplina:

* `ATIVIDADES AULAS/` — Exercícios práticos e páginas desenvolvidas durante as aulas.
* `ATIVIDADES ENTREGUES/` — Situações de Aprendizagem e entregas avaliativas organizadas em pastas próprias (com HTML, CSS externo em `static/css/` e imagens otimizadas).
* `AULAS DOC/` — Roteiros, documentações de apoio e materiais disponibilizados pelo professor.

---

## 🛠️ 2. Tecnologias e Conceitos Aplicados

| Tecnologia / Conceito | Aprendizados Praticados |
| :--- | :--- |
| **HTML5 Semântico** | Estruturação de páginas, formulários com boas práticas de acessibilidade e tabelas de dados. |
| **CSS3 & Estilização** | Estilização externa, layout com Flexbox, consistência visual e responsividade com Media Queries. |
| **Modularização & Mídia** | Separação entre código-fonte, folhas de estilo (`static/css/`) e imagens otimizadas para Web. |
| **Git & GitHub** | Controle de versão com commits organizados e entrega contínua para avaliação. |
